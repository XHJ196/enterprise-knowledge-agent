二、本阶段实现

GlobalExceptionHandler 增加 HttpMessageNotReadableException 处理。
JSON 损坏或缺失返回 400 / INVALID_JSON；覆盖的字段映射错误返回 422 / VALIDATION_ERROR。
错误文案固定，不回传解析器、SQL 或堆栈详情。

application.yaml 启用 fail-on-unknown-properties。
创建请求只接收 name、description，role/createdBy/lifecycle 等未知字段在进入 Service 前拒绝。
JacksonConfiguration 使用 JsonMapperBuilderCustomizer 配置 Textual 类型转换。
数字（整数/小数）和布尔值不能自动转换为 String，请求返回 422。
配置通过 Spring Boot 的自动配置扩展，不手动替换整套 ObjectMapper。

RequestIdFilter 每次生成新 UUID，写入 request attribute 与 X-Request-Id。
成功和错误响应都设置 Cache-Control: no-store，JSON requestId 与响应头相同。
客户端传入合法 UUID 也不会作为本次服务端 ID；保留 filterChain.doFilter。
未来内部调用、异步流和错误分派的追踪仍需在对应阶段验证。
